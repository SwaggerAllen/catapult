# Signpost — capability inventories

What the toy project can already lean on, if it existed for real
(nothing here is provisioned by this fixture — it is the kind of
inventory an intake pass would read):

- An internal DNS entry for the fixed short-link host already exists
  org-wide; Signpost doesn't provision its own domain (see
  `non_goals.md`).
- A shared internal auth layer identifies which team owns a link; this
  toy project treats "who owns a link" as already solved upstream and
  does not re-derive it.
