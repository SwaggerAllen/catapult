# Signpost — forward strategies

Directional intent, not commitments — the kind of forward-looking
note an intake pass would carry alongside a project's frozen input
raft rather than treat as a current requirement:

- If click volume ever matters at real scale, the click-count write
  path is the first thing that would need to move off the hot
  redirect path (e.g. a queue instead of an inline increment) — not
  designed here, just flagged as the direction a real version would
  grow in.
- Custom domains (explicitly out of scope today — `non_goals.md`)
  would be the next feature a real product pass would consider, once
  a team asks for one.
