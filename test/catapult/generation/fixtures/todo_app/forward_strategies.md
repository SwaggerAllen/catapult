# Waypoint — forward strategies

Directional intent, not commitments — the kind of forward-looking
note an intake pass would carry alongside a project's frozen input
raft rather than treat as a current requirement:

- If sharing ever mattered (explicitly out of scope today —
  `non_goals.md`), `lists` is the component that would need an owner
  concept first — `tasks` and `reminders` would not need to change
  just to let two people see the same list.
- Recurring tasks (also out of scope today) would be the next feature
  a real product pass would consider, once "every Monday" comes up
  often enough — not designed here, just flagged as the direction a
  real version would grow in.
