# Waypoint — non-goals

- **No sharing or collaboration.** Every list and task belongs to one
  person. No invites, no shared lists, no "assign this task to
  someone else." That is a different, much bigger product.
- **No recurring tasks.** A task happens once. "Every Monday" is a
  real feature for a real to-do app and a distraction from this
  fixture's actual job — it multiplies the task/reminder relationship
  in ways this small a seed does not need to demonstrate.
- **No push notifications.** A reminder firing means it becomes
  visible in the app (badge, today view) — it does not mean a phone
  buzzes. Delivery channel is out of scope; "did this reminder fire"
  is the only fact the `reminders` component owns.
- **No search.** Finding a task means picking its list, or checking
  today's view. A search bar across every list is a real feature this
  seed does not need to have an opinion on.

This document exists to force the `non_goals` input role to have real
content, per this fixture's own scope (`docs/build-plan.md`'s Phase 5
exit criterion) — it is read as raft evidence, not asserted to shape
any generated tier's output directly (`systems/generation.md`'s
`input.<role>` resolution).
